# release-install Specification

## Purpose
Установка приложения из релиза одной командой: `install.sh` публикуется в assets релиза, сам скачивает zip и `SHA256SUMS.txt`, проверяет целостность до любых изменений в системе, снимает карантинный флаг и устанавливает приложение в `/Applications` — без Xcode, Homebrew и ручных шагов.

## Requirements

### Requirement: Скрипт установки публикуется в assets релиза
Релиз SHALL публиковать `install.sh` в assets вместе с zip-архивом приложения и `SHA256SUMS.txt`, чтобы установка выполнялась одной командой без клонирования репозитория.

#### Scenario: Assets релиза содержат скрипт
- **WHEN** workflow релиза публикует релиз по тегу `vX.Y.Z`
- **THEN** в assets присутствуют `install.sh`, `VPNChainSetup-X.Y.Z-macos-universal.zip` и `SHA256SUMS.txt`

#### Scenario: Скрипт самодостаточен
- **GIVEN** у пользователя только страница релиза, репозиторий не склонирован
- **WHEN** скрипт запускается по инструкции из README
- **THEN** установка проходит полностью: скрипт не требует файлов из репозитория, кроме себя

### Requirement: Выбор версии устанавливаемого релиза
Без аргументов скрипт SHALL устанавливать последний релиз; если первым аргументом передана версия (с `v` или без), скрипт SHALL устанавливать именно её. Несуществующая версия SHALL завершаться ошибкой без изменений в системе.

#### Scenario: Установка последнего релиза по умолчанию
- **WHEN** скрипт запущен без аргументов
- **THEN** скачивается zip и `SHA256SUMS.txt` последнего релиза

#### Scenario: Установка конкретной версии
- **WHEN** скрипт запущен с аргументом `1.2.3` (или `v1.2.3`)
- **THEN** скачиваются файлы релиза `v1.2.3`

#### Scenario: Несуществующая версия
- **WHEN** скрипт запущен с аргументом версии, у которой нет релиза
- **THEN** скрипт завершается с ошибкой, ничего не скачивая и не устанавливая

### Requirement: Проверка целостности до любых изменений в системе
Скрипт SHALL скачивать zip и `SHA256SUMS.txt`, вычислять SHA256 zip и сверять его с суммой из `SHA256SUMS.txt` ДО любого изменения в системе (распаковки в целевые каталоги, снятия карантина, копирования в `/Applications`). При несовпадении суммы, отсутствии или нечитаемости `SHA256SUMS.txt` скрипт SHALL завершаться ошибкой, не внося изменений в систему за пределами своего временного каталога.

#### Scenario: Контрольная сумма совпала
- **GIVEN** zip скачан без повреждений
- **WHEN** вычисленный SHA256 совпадает с записью в `SHA256SUMS.txt`
- **THEN** скрипт продолжает установку

#### Scenario: Контрольная сумма не совпала
- **GIVEN** zip скачан с повреждением или подменён
- **WHEN** вычисленный SHA256 не совпадает с записью в `SHA256SUMS.txt`
- **THEN** скрипт завершается с ошибкой; в `/Applications` нет установленных или изменённых файлов, карантинные флаги не сняты, временный каталог не оставляет артефактов установки

#### Scenario: Файл контрольных сумм отсутствует или не содержит запись о zip
- **WHEN** `SHA256SUMS.txt` не скачался или не содержит строки для скачанного zip
- **THEN** скрипт завершается с ошибкой без установки

### Requirement: Установка со снятием карантинного флага
После успешной проверки суммы скрипт SHALL распаковать zip во временный каталог, снять флаг `com.apple.quarantine` с `VPNChainSetup.app` и скопировать приложение в `/Applications`, запросив `sudo` только при необходимости (если запись без него невозможна). Завершившись успешно, скрипт SHALL напечатать путь установленного приложения и напоминание, что сборка не подписана Apple.

#### Scenario: Установка на чистый Mac
- **GIVEN** на Mac нет Xcode, Homebrew и предыдущей установки приложения
- **WHEN** пользователь запускает скрипт одной командой из README
- **THEN** `VPNChainSetup.app` появляется в `/Applications` без карантинного флага и запускается без предупреждения Gatekeeper о неподписанном приложении, скрипт печатает итог и напоминание о неподписанной сборке

#### Scenario: Приложение уже установлено
- **GIVEN** в `/Applications` уже есть `VPNChainSetup.app`
- **WHEN** скрипт устанавливает новую версию
- **THEN** существующее приложение заменяется новой версией

#### Scenario: Запись в /Applications без sudo
- **GIVEN** пользователь имеет право записи в `/Applications`
- **WHEN** скрипт копирует приложение
- **THEN** `sudo` не запрашивается, установка проходит без пароля

#### Scenario: Запись в /Applications требует sudo
- **GIVEN** запись в `/Applications` без повышения невозможна
- **WHEN** скрипт копирует приложение
- **THEN** запрашивается пароль через `sudo` только на шаге копирования, при отказе в пароле скрипт завершается ошибкой, не оставляя частично скопированного приложения

### Requirement: Минимальные системные требования скрипта
Скрипт SHALL работать на чистом поддерживаемом Mac (macOS 13+) без Xcode и Homebrew, используя только средства, предустановленные в macOS. Скрипт MUST включать `set -euo pipefail` и корректно обрабатывать пути с пробелами — включая каталог загрузки и путь к приложению. Сетевые сбои (нет доступа к github.com, таймаут загрузки) SHALL завершать скрипт ошибкой без изменений в системе.

#### Scenario: Только предустановленные средства macOS
- **GIVEN** чистый Mac без Xcode, Homebrew и дополнительных утилит
- **WHEN** запускается скрипт
- **THEN** все шаги (загрузка, проверка суммы, распаковка, снятие карантина, копирование) выполняются предустановленными средствами macOS

#### Scenario: Пути с пробелами
- **GIVEN** имя пользователя или промежуточный каталог содержит пробелы
- **WHEN** скрипт скачивает и распаковывает архив
- **THEN** шаги выполняются успешно, пути не разбиваются на части

#### Scenario: Сетевой сбой
- **WHEN** загрузка zip или `SHA256SUMS.txt` не удалась
- **THEN** скрипт завершается с понятной ошибкой, система не изменяется
