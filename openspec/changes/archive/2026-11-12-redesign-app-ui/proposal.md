# Proposal

## Why

Приложение работает, но выглядит как технический прототип: экраны собраны из `GroupBox` + `Grid`,
контент зажат в колонку 560 pt, цвета захардкожены (`Color.green`/`Color.blue`), нет статус-пилюль,
empty state, toolbar, меню-команд и accessibility-подписей. Для инструмента, который работает с
root-доступом по SSH и разворачивает сетевую цепочку на двух серверах, «сырой» вид подрывает доверие
к результату: пользователь не может с одного взгляда понять, работает ли цепочка и что именно сломано.

## What Changes

- Новая визуальная система: карточки, статус-пилюли, строки метрик, inline-баннеры, empty state,
  единые отступы и типографика. Только семантические цвета — корректная работа в Dark Mode,
  Increase Contrast и Reduce Transparency.
- Оболочка приложения по HIG: sidebar с группой разделов и сохранением выбранного пункта,
  unified toolbar, меню-команды (⌘R, ⌘↩, ⌘D), осмысленные минимальные размеры окна.
- Переработка пяти экранов: «Подключения» (адаптивная сетка карточек серверов), «Статус»
  (общее состояние цепочки + схема звеньев + метрики), «Установка» (прогресс, таймлайн шагов,
  карточка сводки, лог), «Диагностика» (симптом → результат → советы → опасная зона uninstall),
  «Клиент» (нумерованные шаги).
- Accessibility: подписи для иконочных элементов, полная клавиатурная навигация и default-action,
  уважение Reduce Motion / Reduce Transparency / Increase Contrast.
- Иконка приложения: Assets.xcassets/AppIcon (полный набор размеров), подключение через project.yml.

Поведение не меняется: те же SSH-вызовы, те же тексты ошибок, те же условия доступности действий.

## Capabilities

### New Capabilities

- `app-interface`: требования к пользовательскому интерфейсу macOS-приложения — оболочка окна
  (sidebar, toolbar, меню, размеры), визуальная система (карточки, статус-пилюли, баннеры,
  семантические цвета, тёмная тема), состав и информационная иерархия пяти экранов,
  доступность и иконка приложения.

## Impact

- Код: `Sources/VPNChainSetup/Views/*` (все пять экранов + корневая навигация), `VPNChainApp.swift`,
  новый `Views/DesignSystem.swift`, `ViewModels/*` (только вычисляемые свойства), новый
  `Sources/VPNChainSetup/Resources/Assets.xcassets`, `project.yml`.
- Логика SSH/провижининга, шаблоны конфигов, парсеры и их unit-тесты не затрагиваются:
  `swift test` остаётся без изменений (146 тестов).
- Сборка: `VPNChainSetup.xcodeproj` генерируется, поэтому после добавления файлов и ассетов
  обязателен `xcodegen generate`.
- Вне scope: локализация на другие языки, настройки темы, изменение набора функций,
  распространение/нотаризация приложения.
