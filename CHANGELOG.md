# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-11-12

Первый публичный релиз. Сборка без подписи Apple (см. инструкцию по установке в README).

### Добавлено

- Подключения: профили сервера-входа и сервера-выхода (пароль или ключ ed25519/ECDSA), проверка соединения с отчётом ОС/архитектуры, TOFU-закрепление host key. Секреты — в Keychain, в настройках только не-секретные поля.
- Установка: полная автоматизация цепочки «клиент → сервер-вход → сервер-выход → интернет»: детект окружения AmneziaWG, установка `amneziawg-go`/`amneziawg-tools` по пинам, генерация ключей и параметров обфускации, конфигурация relay-туннеля `10.99.0.0/24` (UDP 51828), юниты systemd, идемпотентные шаги, живой вывод и итоговая сводка.
- Маршрутизация: отбор клиентского трафика по `fwmark` с исключением ответов контейнера клиентам, blackhole kill-switch, анти-утечка IPv6, правила в `DOCKER-USER`, NAT relay-подсети на сервере-выходе.
- Статус и проверки: автоматические проверки ТЗ §10 (handshake, правила, порт, NAT, контейнер) с подсказками; ручной чек-лист.
- Диагностика по симптомам ТЗ §11 и безопасное удаление: снимаются только артефакты приложения (маркер `managed-by: amnezia-chain`), контейнер AmneziaVPN и SSH не затрагиваются.
- Экран «Клиент»: пошаговая инструкция AmneziaVPN (full tunnel, KillSwitch, DNS через туннель, MTU 1380 при проблемах с UDP).
- Локализация интерфейса на русский, санитизация журнала (секреты не попадают в логи).
- 146 unit-тестов; сборка universal (arm64 + x86_64), macOS 13+.

### Известные ограничения

- Приложение не подписано Developer ID и не нотарифицировано — при первом запуске требуется подтверждение Gatekeeper (инструкция в README).
- Не прогонялись проверки kill-switch и reboot-персистентности на реальной паре (пункт 8.2 приёмки); команды для проверки — в `openspec/changes/archive/2026-11-12-macos-vpn-chain-setup-app/design.md`.
