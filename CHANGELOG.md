Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено

- Раздел «Прокси» (опция, по умолчанию выключена): весь исходящий трафик сервера-входа — хостовые сервисы и Docker-контейнеры включённых сетей — направляется через сервер-выход. Маркировка `fwmark` в `mangle OUTPUT`/`PREROUTING`, маршруты и MASQUERADE подсетей на выходе, порядок «выход → вход» с откатом, проверка фактического IP с хоста и из контейнеров.
- Состояние режима — `/etc/amnezia/chain/proxies.json` (0600, маркер `managed-by: amnezia-chain`); отсутствие файла = выключено.
- IPv6-kill-switch при включённом режиме: исходящий IPv6 с входа и из включённых контейнеров блокируется (кроме loopback/link-local).
- Диагностика: проверки `proxy-host-egress`, `proxy-docker-networks`, `proxy-exit-nat`, `proxy-egress-ip` и симптомы «прокси не выходит через сервер-выход», «после включения пропал доступ».
- Uninstall снимает proxy-правила и файлы только по маркеру; контейнер AmneziaVPN и SSH не затрагиваются.

## [0.2.0] — 2026-11-12

Переработка интерфейса. Поведение SSH, провижининга и диагностики не менялось.

### Изменено

- Дизайн-система: карточки с заголовком, иконкой и пояснением, статус-пилюли, строки метрик, inline-баннеры, empty state; только семантические цвета, корректно работают в тёмной теме.
- Оболочка: боковая панель-список разделов (запоминается между запусками), unified toolbar, окно 1040×700 с минимумом 820×560.
- Меню «Цепочка»: «Обновить статус» (⌘R), «Начать установку» (⌘↩), «Диагностировать» (⌘D); недоступные пункты задизейблены.
- «Подключения»: карточки серверов в адаптивной сетке, сегментированный выбор аутентификации, порт SSH в блоке «Дополнительно», результат проверки — баннером в карточке.
- «Статус»: итоговый вердикт по цепочке, схема «Клиент → Сервер-вход → Сервер-выход → Интернет», сводка проверок «N из M», ручной чек-лист свёрнут.
- «Установка»: прогресс «шаг N из M», таймлайн шагов, карточка сводки с напоминанием про UDP 51828, журнал с копированием.
- «Диагностика»: сводка результатов, нумерованные советы, очистка сервера — в отдельной карточке с явным подтверждением.
- Доступность: подписи для VoiceOver, подсказки, Return и ⌘↩ в формах, уважение Reduce Motion.

### Добавлено

- Иконка приложения (AppIcon, все размеры 16–512 pt с @1x/@2x). Генератор — `scripts/make-app-icon.swift`.
- Спецификация интерфейса `openspec/specs/app-interface/`.

## [0.1.0] — 2026-11-12

Первый публичный релиз. Сборка без подписи Apple (см. инструкцию по установке в README).

### Добавлено

- Подключения: профили сервера-входа и сервера-выхода (пароль или ключ ed25519/ECDSA), проверка соединения с отчётом ОС/архитектуры, TOFU-закрепление host key. Секреты — в Keychain, в настройках только не-секретные поля.
- Установка: полная автоматизация цепочки «клиент → сервер-вход → сервер-выход → интернет»: детект окружения AmneziaWG, установка `amneziawg-go`/`amneziawg-tools` по пинам, генерация ключей и параметров обфускации, конфигурация relay-туннеля `10.99.0.0/24` (UDP 51828), юниты systemd, идемпотентные шаги, живой вывод и итоговая сводка.
- Маршрутизация: отбор клиентского трафика по `fwmark` с исключением ответов контейнера клиентам, blackhole kill-switch, анти-утечка IPv6, правила в `DOCKER-USER`, NAT relay-подсети на сервере-выходе.
- Статус и проверки: автоматические проверки ТЗ §10 (handshake, правила, порт, NAT, контейнер) с подсказками; ручной чек-лист.
- Диагностика по симптомам ТЗ §11 и безопасное удаление: снимаются только артефакты приложения (маркер `managed-by: amnezia-chain`), контейнер AmneziaVPN и SSH не затрагиваются.
- Экран «Клиент»: пошаговая инструкция AmneziaVPN (full tunnel, KillSwitch, DNS через туннель, MTU 1380 при проблемах с UDP).
- Локализация интерфейса на русский, санитизация журнала (секреты не попадают в логи).
- 146 unit-тестов; сборка universal (arm64 + x86_64), macOS 13+.

### Известные ограничения

- Приложение не подписано Developer ID и не нотарифицировано — при первом запуске требуется подтверждение Gatekeeper (инструкция в README).
- Не прогонялись проверки kill-switch и reboot-персистентности на реальной паре (пункт 8.2 приёмки); команды для проверки — в `openspec/changes/archive/2026-11-12-macos-vpn-chain-setup-app/design.md`.
